🔷 Coupling and Cohesion

These are two of the most important concepts in LLD and OOP.

Good Design = Low Coupling + High Cohesion

🔹 Coupling

What is it?

Coupling measures how much one class depends on another class.

👉 Lower coupling is better.

❌ High Coupling

Java 
class Engine {
    public void start() {
        System.out.println("Engine started");
    }
}

class Car {
    private Engine engine = new Engine(); // Tight coupling
    public void startCar() {
        engine.start();
    }
}

public class Main {
    public static void main(String[] args) {
        Car car = new Car();
        car.startCar();
    }
}

Output

Engine started

Car is tightly dependent on a specific Engine.
If Engine changes, Car may also need changes.

✅ Low Coupling

Java 
interface Engine {
    void start();
}

class PetrolEngine implements Engine {
    public void start() {
        System.out.println("Petrol Engine started");
    }
}

class ElectricEngine implements Engine {
    public void start() {
        System.out.println("Electric Engine started");
    }
}

class Car {
    private Engine engine;

    public Car(Engine engine) {
        this.engine = engine;
    }

    public void startCar() {
        engine.start();
    }
}

public class Main {
    public static void main(String[] args) {

        Engine petrolEngine = new PetrolEngine();
        Car petrolCar = new Car(petrolEngine);
        petrolCar.startCar();

        Engine electricEngine = new ElectricEngine();
        Car electricCar = new Car(electricEngine);
        electricCar.startCar();
    }
}

Output

Petrol Engine started

Electric Engine started

Now Car depends on an Engine abstraction, not a concrete class Engine.

🔹 Cohesion

What is it?

Cohesion measures how closely related the responsibilities of a class are.

👉 Higher cohesion is better.

❌ Low Cohesion

Java 
class UserService {
   void registerUser() {}
   void sendEmail() {}
   void generateReport() {}
   void processPayment() {}
}

One class is doing many unrelated things.

✅ High Cohesion

Java 
class UserService {
   void registerUser() {}
}

class EmailService {
   void sendEmail() {}
}

class ReportService {
   void generateReport() {}
}

Each class has one focused responsibility.

🧠 Easy Real-World Example

Coupling

A TV connected to a specific remote only.
High dependency → High Coupling

A universal remote works with many TVs.
Less dependency → Low Coupling

Cohesion

A knife is designed only for cutting.
High Cohesion

A tool that is a knife, spoon, hammer, screwdriver, and torch all together.
Low Cohesion

🎤 Summary

Coupling is the degree of dependency between classes, while cohesion is the degree to which the responsibilities within a class belong together.

Good software design aims for low coupling and high cohesion.

🧠 Memory Trick

Coupling → Between classes

Cohesion → Within a class
