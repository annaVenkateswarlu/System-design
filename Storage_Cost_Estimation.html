💾 Storage Cost Estimation — A Complete Guide

🌐 Bandwidth vs Throughput (Real Meaning)

📦 1️⃣ Bandwidth = Maximum Capacity

👉 Definition:

The maximum amount of data that can be transferred per second

💡 Example:

Your internet plan = 100 Mbps

📐 Standard Formula

Bandwidth = Total Data / Time

👉 Units:
  • Data → bits / bytes (MB, GB, TB)
  • Time → seconds
✅ Result:
  • bps (bits per second)
  • Mbps, Gbps
⚡ Important Conversion

👉 Always convert:

1 Byte = 8 bits

So:

Bandwidth (bps) = (Data (Bytes) × 8) / Time (seconds)

⚡ 2️⃣ Throughput = Actual Speed You Get

👉 Definition:

The real amount of data actually transferred per second

💡 Example:

You get only 60 Mbps

⚖️ Key Difference

Feature Bandwidth Throughput
Meaning Max capacity Actual speed
Controlled by Network capability Real conditions
Example 100 Mbps 60 Mbps

🌍 Real Example

  • 👉 You have: 100 Mbps connection
  • 👉 But: Watching video from slow server
  • 👉 Result: You get only 20 Mbps
  • 👉 That 20 Mbps = throughput

🧠 Summary

  • 👉 Bandwidth is what system can handle
  • 👉 Throughput is what system actually delivers

⚡ Interview One-Liner

👉 Bandwidth is the maximum data transfer capacity of a network, while throughput is the actual rate of successful data transfer, which is usually lower due to real-world constraints.

💸 Cost Breakdown Overview

👉 We consider only:

  • 🖥️ Compute (Servers)
  • 💾 Storage
  • ⚖️ Load balancers
  • 🌐 Bandwidth
  • 📊 Database
  • ⚡ Caching (Redis)
  • 📡 CDN
  • 📈 Logging / Monitoring
  • 🔁 Replication infra

💾 1️⃣ Storage Cost (Per 1 TB)

☁️ Using cloud like Amazon Web Services S3:

👉 ~$20–25 per TB/month

👉 So:
  • 1 TB ≈ $20/month
  • Yearly ≈ $240
🔁 With Replication (Very Important)

Most systems use: 2x or 3x replication

👉 Cost becomes:

  • 2x → $40/month
  • 3x → $60/month

💾 Backups

Backup storage (~cheap tier): ~$5–10/TB/month

🖥️ 2️⃣ Compute Cost (Servers)

👉Server cost is mainly monthly rent for computing power, NOT depending on storage.

👉 Handles:
  • Redirect requests
  • API calls
📌 Typical setup:

Small scale:

  • 2–3 servers → $50–100/month each

👉 Total: $150–300/month

🔥 At Scale (Millions of requests)
  • Auto-scaling servers
  • Load balancers

👉 Cost: $1,000 – $5,000/month

🌐 3️⃣ CDN Cost (Very Important)

👉 For fast redirection globally

☁️ Using CDN (like CloudFront):

👉 1 TB data transfer ≈ $80–$82

Higher usage → cheaper (volume discount)

👉 Example CDN providers:
  • Amazon CloudFront
  • Cloudflare
  • Akamai
⚠️ But real systems :

Analytics + metadata + logs

👉 CDN cost: $50 – $500/month (scale dependent)

📊 4️⃣ Database Cost

👉 Database cost is mainly based on storage + compute + scaling features

👉 1 TB storage cost ≈ $20 – $256 per month

👉 Stores: Short URL → Long URL mapping

📌 Options:
  • SQL / NoSQL DB
  • Managed DB: $100–500/month
🔥 At Scale:
  • Sharding
  • Replication

👉 Cost: $500 – $5,000/month

🔁 5️⃣ Replication (DB Level)

Multi-region replication

👉 Doubles or triples DB cost

📚 6️⃣ Indexing Cost

👉 Needed for:

  • Fast lookup
  • Analytics

👉 Adds: $100–1000/month

📦 7️⃣ Logging & Analytics Infra

👉 For:

  • Click tracking
  • User behavior

🔧 Tools :

  • Kafka / ELK / BigQuery

👉 Cost: $500 – $5,000/month based on traffic

🌐 8. Bandwidth Cost (Biggest Cost)

👉 Cloud data transfer cost of 1 TB bandwidth ≈ $50 – $52 (rough avg of 720p quality)

🎥 Example: Zoom Cost Calculation

🎥 Given Data

  • Users = 300 Million (300M)
  • Each user uses 20 minutes/day
  • 1 hour recording = 300 MB

🧠Step 1: Convert Usage Time

👉 20 minutes = 1/3 hour

💾 Step 2: Storage per User per Day

👉 If 1 hour = 300 MB

👉 Then 20 min:

300 × (1/3) = 100 MB per user/day

💾 Step 3: Total Daily Storage

300M users × 100 MB = 30,000,000 MB

👉 Convert:

  • = 30,000 GB
  • = 30 TB per day

📅 Step 4: Monthly Storage

30 TB × 30 days = 900 TB/month

💰 Step 5: Storage Cost

👉 Using ~$20/TB:

900 × $20 = $18,000/month

🔁 With Replication (3x):

$18,000 × 3 = $54,000/month

🌐 Step 6: Bandwidth Calculation

👉 Each user sends + receives data

Per user: 100 MB/day

Total: 300M × 100 MB = 30 TB/day

📅 Monthly Bandwidth

30 TB × 30 = 900 TB/month

💰 Bandwidth Cost (~$50/TB)

900 × $50 = $45,000/month

🌐 Step 7: CDN Cost (~$80/TB)

900 × $80 = $72,000/month

🖥️ Step 8: Compute Cost

👉 Massive scale:

  • Video processing
  • Routing
  • Encoding

👉 Estimated: $50,000 – $200,000/month

📊 Step 9: Database Cost

👉 Stores:

  • Users
  • Meetings metadata

👉 Estimated: $10,000 – $50,000/month

📦 Step 10: Logging & Analytics

👉 Huge traffic logs:

$20,000 – $100,000/month

💵 🔥 Total Cost

≈ $250K – $500K+ per month
