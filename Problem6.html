Problem 6

🌍 Global Latency Optimization: Australia (80ms) vs India (600ms)

👉 Interviewer asks:

Page loads in 80 ms (Australia) but 600 ms (India).
Same backend, same code.
What will you do?

🎯 Problem Analysis:

Since the backend and code are the same, the issue is most likely due to network latency caused by geographical distance.

  • 👉 Australia Users → close to server → fast response
  • 👉 India Users → far to server → slow response

👉 Solution: Bring data closer to user

🔵 1. Use CDN (First & Best Answer)

"I would use a CDN like Cloudflare to serve static content closer to users."

💡 How it works:

User in India → gets data from India CDN edge

No need to hit far backend server

👉 Result:

Huge latency reduction (600ms → ~100–200ms)

📦 What CDN Caches:

  • ✔ Images
  • ✔ CSS / JS
  • ✔ Static APIs (optional)

🟡 2. Multi-Region Deployment

Deploy backend in multiple regions.

💡 Why:

Reduce round-trip time (RTT)

👉 Example:

  • AWS Mumbai region for India
  • AWS Sydney for Australia

🟣 3. Edge Computing

What it is: Run logic closer to the user (edge locations) instead of central server

✅ What you move to edge:

  • Authentication checks
  • Simple API responses
  • Personalization
  • A/B testing logic

👉 Example:

Instead of request going India → Australia → back, it is handled at nearby edge node

🚀 Result:

  • Ultra low latency
  • Faster response than even backend

🟢 3. Geo-Based Load Balancing

💡 What it does:

Routes user to nearest server

✅ Example:

  • India user → Mumbai region
  • Australia user → Sydney region

👉 Done via:

  • DNS-based routing
  • Geo-aware load balancers

💬 One Line Answer

Since the backend and code are the same, the issue is likely due to network latency caused by geographic distance. To solve this, I would first use a CDN to cache static content near users. Then, I would use edge computing to execute lightweight logic closer to users. I would implement geo-based routing to direct users to the nearest region and use regional load balancers to distribute traffic efficiently. Finally, I would deploy the backend in multiple regions to reduce round-trip latency.

🔥 Clean Comparison

Concept Role
CDN Cache static content
Edge Computing Run logic near users
Geo Routing Send user to nearest region
Load Balancer Distribute traffic within region

🧠 Interview Tips

  • Identify the root cause — Same code = network latency issue
  • Start with CDN — First and best answer
  • Show progression — CDN → Edge → Multi-region
  • Know the numbers — 600ms → 100-200ms with CDN
  • Consider all layers — Static + Dynamic + Routing
